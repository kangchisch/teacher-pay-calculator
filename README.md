# 日代課老師薪資查詢

直接以瀏覽器開啟 `index.html` 即可使用，不需要先上傳網站。

## 更新薪資版本

薪資資料都在 `salary-data.js` 的 `versions` 清單中。新增版本時，將新的版本物件放在清單最前面；網站會自動把第一筆顯示在最上方並預設選取。每一筆薪級含有：

- `grade`：薪級
- `basePay`：本俸
- `researchAllowance`：學術研究費
- `homeroomAllowance`：導師費

請保留逗號、引號與括號格式。

## 更新規定與依據

網站最下方的內容來自 `site-notes.js`。直接修改每筆資料的 `title`（標題）與 `content`（內容）即可；內容要換行時，請使用 `\n`。

## 40 學分班規則

40 學分班無教師證時固定以 245 級試算；有教師證時最高可選薪級為 500。
